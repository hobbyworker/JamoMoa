# JamoMoa v0.9.15

Finder와 단축어 연동이 추가된 기능 릴리즈입니다.

## 새 기능

- **Finder 우클릭 메뉴** — 파일이나 폴더를 우클릭하면 *서비스 ▸ 자모모아:
  합치기 / 분해 / 열기*가 나타납니다. 합치기·분해는 그 자리에서 바로
  실행되고(선택한 항목만 — 폴더는 폴더 이름만 바뀝니다), 열기는 자모모아
  창으로 불러와 검토할 수 있습니다.
- **단축어 지원** — 단축어 앱에 *파일 합치기 / 분해*와 *텍스트 합치기 /
  분해* 동작이 추가됐습니다. 자동화에 끼워 넣거나 Finder의 빠른 동작으로
  등록해 쓸 수 있습니다.
- **변환 결과 알림** — Finder 서비스로 변환을 실행하면 결과를 알림으로
  알려줍니다. 설정에 *알림* 탭이 새로 생겨 켜고 끄거나 빠른 옵션에 올릴 수
  있고, macOS 알림 권한이 꺼져 있으면 안내와 함께 시스템 설정 바로가기를
  보여줍니다.
- **새 앱 아이콘** — macOS 26의 새 아이콘 스타일에 맞춰 아이콘을
  교체했습니다.

## 개선

- **읽을 수 없는 항목 안내** — 권한이 없어 열 수 없는 폴더처럼 읽지 못한
  항목은 조용히 빠지지 않고 목록 위에 경고로 표시됩니다.
- **접근성** — 목록 행의 제거 버튼을 키보드와 VoiceOver로도 사용할 수
  있습니다.
- 작업이 진행 중일 때 들어온 드롭은 무시되지 않고 명확히 되돌려집니다.

## 버그 수정

- 심볼릭 링크, 네트워크 볼륨(NAS), 정규화에 민감한 볼륨에서 이름이 잘못
  바뀌거나 다른 파일을 덮어쓸 수 있던 경우를 바로잡았습니다.
- 적은 수의 항목을 변환할 때도 진행 상황이 제대로 갱신됩니다.
